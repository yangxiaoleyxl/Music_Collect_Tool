# MusicDownload

A music utility with a command-line entry and an optional desktop window.

The command-line entry uses `musicdl` and does not install PySide6. The window uses PySide6.

## Requirements

- Command line: Python 3.10 or newer
- Window: Python 3.13

## Setup

Create a virtual environment, then install one requirements file:

- `requirements-cli.txt` for the command line
- `requirements.txt` for the window

Downloaded audio, virtual environments, and local caches are not part of this repository.
